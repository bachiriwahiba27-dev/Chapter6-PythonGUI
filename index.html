Introduction · GUI programming with Tkinter

Programs do not have to talk through a black terminal. A graphical user interface (GUI) lets users click, type and see results in windows.

Same program, two interfaces

What is Tkinter?

  • The standard GUI library of Python
  • Built on the Tcl/Tk toolkit
  • Works on Windows, macOS and Linux
  • Included with Python (on Ubuntu/Debian: sudo apt install python3-tk)
  • Imported with import tkinter as tk
import tkinter as tk
print(tk.TkVersion)
Output

Why build a GUI?

  • Usability: no commands to remember, everything is visible
  • Feedback: results, errors and plots appear instantly
  • Safer input: menus, sliders and checkboxes restrict what users can enter
  • Engineering tools: monitoring panels, data loggers, simulators and control interfaces

The five notions in one line




Class
A blueprint that describes the attributes and methods of a type.


Object
An instance of a class, with its own values.


Constructor
The  __init__  method, called when the object is created.


Attributes
Variables that store the state of the object (name, age).


Methods
Functions of the class that describe its behavior.




💡 You will meet these notions in every Tkinter program: tk.Tk() and tk.Button(...) call a constructor and create objects, button.pack() is a method call, and options such as text= are values the widget object stores.

Understanding bind(): events as functions


widget.bind(sequence, function) attaches a function to an event on a widget. When the event happens while mainloop() runs, Tkinter calls the function and passes it an event object describing what happened.


SequenceFires whenIn this app


<Button-1>left mouse button is pressedConvert button (bind mode)


<Return>Enter key is pressedEntry: convert from the keyboard


<Key>, <Double-Button-1>any key / double clickOther examples


  • 1. Pick the event: the sequence has the form <modifier-type-detail>, for example <Button-1> = type Button, detail 1 (left button).
    • 

  • 2. Give a function: a named function or a lambda. It receives one argument, the event. If you do not need it, write lambda e: convert().
    • 

  • command vs bind: command= only handles a button click, without an event object. bind() works on any widget and any event, and can add several handlers with add="+".
